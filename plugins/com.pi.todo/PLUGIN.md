# 待办

面板里的任务清单。任务状态存在插件后端，面板只是它的投影——关掉面板再打开不会丢。

## 三个工具

### `todo_add({ title, note? })`

加一条待办。`title` 是短标题，`note` 放细节。

调用后会给出一条卡片（`messageRenderer: todo_add`），用户能直接在对话里看到加了什么。

### `todo_list()`

列出全部待办，标出哪些还没完成。

### `todo_done({ title })`

把一条**未完成**的待办标记为完成。

匹配规则是**标题包含**你给的字串（`title.includes(...)`），不是精确相等；有多条命中时取**最近添加的那条**。找不到未完成的匹配项会报错——报错说明要么标题打错了，要么这条已经完成了。

## 什么时候用

- 用户明确要求记住 / 提醒某件事
- 一件事需要拆成多步推进，清单能帮用户看清楚进度

**纯工作跟踪用这个。** 用户要想被系统通知提醒，说清楚这是应用内清单，不是系统提醒。

## 边界

- 只在这个应用里可见，不写系统日历、不发系统通知。
- 没有删除和编辑工具：任务只能加和标记完成。想改内容就新加一条、把旧的标完成。
