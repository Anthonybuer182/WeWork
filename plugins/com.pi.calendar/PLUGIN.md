# 日历

一份**本地**的日程清单，存在插件后端。面板里的时间线只是它的投影。

## 两个工具

### `calendar_add_event({ title, time, note? })`

记一条日程。

**`time` 是自由文本，原样存下来，不做解析。** 所以写「明天下午 3 点」「2026-09-01 10:00」
「下周五」都可以——但它就是一段字符串，系统不会拿它算日期、排顺序、也不会到点提醒。
`time` 留空会存成「未定时间」。

返回时会复述记下的内容，可以核对一遍。

### `calendar_list_upcoming()`

列出已记录的日程。

> 名字叫 upcoming，但**实际返回全部日程**，不按时间筛、也不排序。想找最近的几条，
> 自己从返回里挑。

## 什么时候用

- 用户说了明确的会议、截止时间、约会，要你记下来
- 用户问「我之前记的那个日程」

时间能问就问清楚一点（最好是「2026-09-01 10:00」这种能直接读的格式），
因为它只是文本，模糊的「改天」记下来后面没法用。

## 边界

- **不会提醒。** 虽然权限里声明了通知，但这一版没有到点提醒的实现——不要跟用户承诺「到时候会提醒你」。
- **不连外部日历。** 不读也不写系统日历、Google Calendar、CalDAV，只在本应用内可见。
- 没有删除和编辑工具：日程只能加和看。
