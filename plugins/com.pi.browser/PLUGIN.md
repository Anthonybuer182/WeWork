# 浏览器自动化

内嵌的浏览器。有个实时预览面板（`browser`）显示真实页面，旁边一条工具栏。

## 三个工具

### `browser_navigate({ url })`

打开一个网址并等它加载完。返回最终地址和页面标题。地址没写协议会自动补 `https://`。

### `browser_get_state()`

读当前页面的地址和标题。**不返回页面正文**——要内容用截图。

### `browser_screenshot({ fullPage? })`

截当前页面，返回一张 PNG。

这个工具返回的是**真正的图片**，你能直接看到页面长什么样——文字、排版、图标、图表都看得到。
所以**看页面内容就靠截图**。`fullPage: true` 截整个可滚动页面，否则只截可视区域。

## 怎么拿到页面内容

没有"读页面文字"的工具。要看内容就 `browser_screenshot` 再自己看。

- 页面很长时，先截可视区，配合滚动（见下方边界）分段看
- 截出来的图会占上下文，别没事就整页截

## 你**不能**做的事

工具只暴露了上面三个。**下面这些没有工具，别试着绕**：

- ❌ 点击链接或按钮
- ❌ 填表单、登录
- ❌ 提取页面文字 / DOM / HTML
- ❌ 执行页面里的 JS

需要在页面上操作（点击、填表），**告诉用户用工具栏或面板自己操作**，你负责看结果。
工具栏上有后退 / 前进 / 刷新 / 地址栏，用户可以自己用。

## 什么时候用

- 用户给了链接，问"这个页面是什么" / "帮我看看"
- 需要在线查资料，而工作区的文件里没有
- 验证一个网页能不能打开、内容对不对

## 边界

- 页面在**内嵌面板**里打开，不是系统浏览器——用户切换面板时页面会保留（keepAlive 常驻）。
- 有些站点会检测自动化环境或需要登录，可能打不开或显示不全；截出来什么样就说什么，别猜。
